# Project 01 – Number Analyzer

## 1. Giới thiệu

Number Analyzer là một chương trình tính toán thuộc bài tập lớn trong môn học nhập môn lập trình C

## 2. Tính năng

- Kiểm tra số nguyên tố
- Tìm ước chung lớn nhất (UCLN).
- Tìm bội chung nhỏ nhất (BCNN).
- Đảo ngược số.
- Đếm các chữ số
- Tính Giai Thừa
- Tính Fibonacci.

## 3. Các phần mềm sử dụng

- Ngôn ngữ lập trình: C
- IDE: Code::Blocks
- Compiler: GCC

## 4. Cấu trúc dự án

## 5. Cách thực hiện chương trình

1. Sao chép hoặc tải repository này xuống.
2. Mở file dự án bằng Code::Blocks.
3. Xây dựng dự án.
4. Chạy chương trình.

## 6. Mục tiêu học tập

- Hiểu các hàm trong C.
- Luyện tập khai báo và định nghĩa hàm.
- Sắp xếp mã nguồn thành nhiều file.
- Luyện tập các thuật toán cơ bản.
- Học Git và GitHub.
